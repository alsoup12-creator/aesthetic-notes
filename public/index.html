把安装包中的 aesthetic-notes 整个文件夹放入该 Agent 支持的本地 Skill 目录，再交给它上面的使用指令。需要本机文件读取和脚本运行能力，以及 Node.js 22 或以上版本。

云端 Agent 无法直接读取这台电脑的文件，可以在笔记列表导出参考包交给它。
